# Binh 13

> **Binh 13** theo thời gian thực cho 2 người chơi

Người chơi chia sẻ mã phòng 6 ký tự để vào game — không cần tạo tài khoản. Mỗi người nhận 13 lá bài và sắp xếp thành 3 nhóm. Server so sánh kết quả và xác định người thắng.

---

## Cách chơi

1. Nhập tên → Tạo hoặc tham gia phòng bằng mã code
2. Chờ trong sảnh đợi người chơi thứ hai
3. Sắp xếp 13 lá bài thành 3 nhóm:
   - **Hậu** (5 lá) — bài mạnh nhất, xếp hạng theo luật poker
   - **Trung** (5 lá) — phải yếu hơn Hậu
   - **Tiền** (3 lá) — bài yếu nhất, không tính sảnh/đồng chất
4. Nộp bài — server so sánh tất cả các nhóm cùng lúc
5. Thắng 2 trong 3 nhóm để giành chiến thắng

**Bài cháy** (Hậu < Trung) sẽ thua cả 3 nhóm.
